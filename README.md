# DNP-ConFormerv2

**DNP-ConFormerv2: Advancing Medical Anomaly Detection via Diverse Normal Prototypes and Paired Pseudo Anomaly Supervision**

DNP-ConFormerv2 is the journal extension of [DNP-ConFormer](https://github.com/liluhu0/DNP-ConFormer) for medical anomaly detection and localization.

Building on the adaptive prototype-guided reconstruction of DNP-ConFormer, DNP-ConFormerv2 introduces Paired Pseudo Anomaly Synthesis (PPAS), paired feature restoration with shared normal-source targets, and supervised spatial refinement.
